# Misattitude — プライバシーポリシー / Privacy Policy

**最終更新日 / Last updated:** 2026-05-07

---

## 日本語

### 1. はじめに

Misattitude（以下「本アプリ」）は、回転姿勢（attitude）を 3D で可視化する
教育用ツールです。本アプリの開発者（takarakasai）は、利用者のプライバシーを
最優先に考えています。

### 2. 収集する情報

**本アプリは、利用者のいかなる個人情報・利用情報も収集しません。**

具体的には以下を一切収集・送信・保存しません：

- 個人を特定できる情報（氏名、メールアドレス、電話番号、住所等）
- 端末識別子（IMEI、広告 ID、デバイス ID 等）
- 位置情報
- 連絡先、カレンダー、写真、ファイル等の端末上のデータ
- 利用状況・操作ログ・クラッシュレポート
- ネットワーク通信を伴うあらゆるデータ

### 3. アプリの権限

本アプリは Android のいかなる特別な権限も要求しません。
インターネット接続権限すら宣言されていないため、本アプリが外部サーバーと
通信することは技術的に不可能です。

### 4. 第三者への提供

データを一切収集していないため、第三者への提供もありません。
本アプリには広告 SDK、分析 SDK、クラッシュ解析 SDK が一切組み込まれていません。

### 5. 子供のプライバシー

本アプリは 13 歳未満を主たる対象としていませんが、データを収集しないため、
お子様が安全に利用できます。

### 6. 本ポリシーの変更

本ポリシーが変更される場合、本ページにて告知します。実質的な変更がある場合は
アプリ内通知や更新リリースノートで告知します。

### 7. お問い合わせ

ご質問・ご要望は GitHub Issues にてご連絡ください：
https://github.com/takarakasai/misattitude (※リポジトリ未公開の場合は連絡先メールアドレスに置き換える)

## English

### 1. Introduction

Misattitude (the "App") is an educational tool for 3D visualization of rotation
attitude. The developer (takarakasai) places the highest priority on user privacy.

### 2. Information We Collect

**The App does not collect any personal or usage information from users.**

Specifically, we do **not** collect, transmit, or store any of the following:

- Personally identifiable information (name, email, phone, address, etc.)
- Device identifiers (IMEI, advertising ID, device ID, etc.)
- Location data
- On-device data such as contacts, calendar, photos, or files
- Usage statistics, interaction logs, or crash reports
- Any data that requires network communication

### 3. App Permissions

The App requests no special Android permissions. It does not even declare the
INTERNET permission, so it is **technically impossible** for the App to
communicate with any external server.

### 4. Third-Party Sharing

Because we collect no data, none is shared with third parties. The App contains
no advertising SDKs, analytics SDKs, or crash-reporting SDKs whatsoever.

### 5. Children's Privacy

The App is not primarily targeted at children under 13. However, since we
collect no data, children may use it safely.

### 6. Changes to This Policy

If this policy changes, we will announce the changes on this page. Any
substantive changes will also be announced via in-app notification or release
notes.

### 7. Contact

For questions or feedback, please open an issue on GitHub:
https://github.com/takarakasai/misattitude
(Or replace with a contact email if the repository is not public.)
